# 视觉 UX 与美术验收

用于制作、修改与风格评审。评审原始素材和最终 PPTX 渲染图；生成器预览看起来正常不代表原生文字叠加后正常。

## 1. 从参考提取可检查的设计约束

查看全稿联系表，再按相同用途选择几组代表页。记录以下具体观察，避免仅用“高级、精致、金蓝色”等词概括：

- **线条**：轮廓、连接线、注释线的相对粗细；颜色、转角、端点和交叉处理。
- **物件尺度**：图标与文字的大小关系；主视觉占比；哪些细节保留、哪些省略。
- **材质与空间**：高光宽度、渐变反差、阴影范围、立体厚度、透视和空间层次。
- **图解语法**：节点表示什么；箭头表示数据流、控制流、因果还是顺序；边界、分层、分支、闭环有何语义。
- **排版**：标题、分组标题、正文和脚注的层级；行长、对齐、阅读顺序及安全留白。
- **全稿节奏**：不同问题使用何种图式；信息密度如何变化；哪些页面需要沉静，哪些承担总览。

内容变化时借用相同的设计原则，不照搬原图过时的文字和论证。参考本身的缺陷也应记录。

## 2. 在扩大制作前验证风格

整套重做通常先制作约 2–3 个有代表性的页面：一页主叙事、一页机制图、一页较密集架构／比较图。小改动只检查受影响页面。

以最终字体叠字并渲染，再与原参考同尺寸对照。缩略图检查重心与节奏；接近实际演示尺寸检查可读性；原始像素附近检查笔触和生成瑕疵。

这是自主迭代的质量检查，不要求用户重复批准已经授权的工作。只有用户要求先看样稿，或方向缺失会实质影响结果时，才把样稿作为交互节点。

若新稿已经明显偏向粗重的立体物件，不应继续用该新稿作为后续页面的主要风格参照。回到被用户认可的参考，修正一组具体变量后再扩大制作。

## 3. 先核对图形表达，再打磨局部外观

以原文为内容权威，同时审查完整设计和最终渲染。生成图自身可能已经画错；忠实复刻它不能证明内容正确。对机制图和定量图，优先检查这些可改变结论的关系：

- 逐条连接核对起点、终点、方向和含义。多画一条依赖、捷径或返回边也可能改变逻辑；不能只检查必需节点和文字是否出现。
- 相同量纲、同一标尺上的长度、面积或位置应支持所标数值。文字算式正确不能抵消图形比例错误；仅作示意时明确其非定量性质，避免绘制会暗示共用数值尺度的坐标。
- 注释里的编号、字母和缩写必须能对应到可见对象；不要只在页面数据内部有 ID，观众却无法从图上找到它。
- 表头与数值检查列归属，分组标题检查边界归属；文本框内无溢出不代表没有压到表格线或跨入邻区。

先把同一页或相邻区域已观察到的问题收集在一起，再批量修改和复看受影响部分。不要在主关系尚有矛盾时，连续多轮只微调个别字的边距。记录可见问题和修复依据，避免用反复渲染次数或自评分替代它们。

## 4. 同标准评分

下表为可调整的默认权重。项目有明确目标时采用相应权重，并同时用于参考与候选。共享复用页面不应被当作新增美术能力的证据。

| 维度 | 默认权重 | 评分看什么 |
| --- | ---: | --- |
| 美术精细度 | 25% | 线条控制、明暗克制、空间厚度、图标细节、尺度一致和生成瑕疵 |
| 图形表达论证 | 25% | 看图能否识别对象、关系、控制边界与因果；连接是否准确、可解释 |
| 层级与留白 | 15% | 首读重点是否明确；标题、图和注释的比例；空白是否支持阅读 |
| 阅读与扫描效率 | 15% | 演示尺寸下的字体、行长、对齐、标签归属、阅读路径和遮挡 |
| 全稿节奏与辨识度 | 10% | 图式是否适合不同论点；重复是否有意义；各页能否区分 |
| 视觉一致性 | 10% | 色彩、字体、尺度及符号语义是否一致；一致性是否建立在合适的视觉语言上 |

评分锚点：

- **9–10**：接近精修出版质量，图形承担明确论证，只有细微可改之处。
- **7–8**：专业、可用，主要关系清楚；存在局部密度、细节或节奏问题。
- **5–6**：基本可读，但粗糙、模板重复、装饰过量或层级失衡明显。
- **3–4**：关键对象或关系容易误读，频繁拥挤、错位或不一致。
- **1–2**：无法有效理解或完成演示用途。

每个扣分点附页码和可见证据，例如“六条带状图未标注层次，无法知道各条对应什么”。不要只写“感觉不够高级”。分数是启发式判断，可用半分或近似总分，不宣称统计显著性。

明确评分对象：单张插画、完整设计页、最终 PPTX 页面和整套稿件不能共用一个通过结论。用户指定评分目标时，采用相同标准复核实际要求的对象；插画分数再高也不能证明图文布局或全稿节奏达标。机械检查未检出问题，仅说明该检测范围内未发现问题，不填写为美术通过。

从联系表检查是否反复使用同一图文分栏、是否存在无理由的密度差异，再在实际演示尺寸检查代表页与密集页。用户要求整合图文时，查看关键标签是否附着在对应图形上、图本身能否解释关系；保留两栏需有内容上的理由。用户要求重新构图时，记录整页构图实际改变了什么，不能仅用新图片文件或更多检查次数证明完成。

用户要求沿用既有风格时，比较每个重要维度而非仅总分。可读性略有提高不能自动抵消美术精细度和图形语义的明显退步。目标是消除相对参考的实质差距，不把某个固定分数变成所有项目的硬门槛。

## 5. 常见失败及修正方向

| 观察 | 应采取的修正 |
| --- | --- |
| 几乎每页都出现机柜、齿轮、盾牌与粗箭头 | 按该页论点重新选择图式；删除没有独立语义的重复物件 |
| 图标变大、立体厚度增加、亮面反差强 | 对照原稿降低厚度、阴影与高光，恢复图标与正文的尺度关系 |
| 图比原版复杂，机制却更难理解 | 给每个节点／连接写出语义；删减装饰，补充关键边界或标签 |
| 顶部大标题和巨型插画挤压正文 | 重新分配面积，调整图形而非一味缩小字号 |
| 缩略图统一，但连续看很多页难以区分 | 按比较、因果、分层、闭环、总览等任务改变构图 |
| 有字图漂亮，无字图叠文字后错位 | 以最终母版渲染为准修正素材及布局，不只调 OCR 框 |
| 放大图片后仍然柔软、线条粗糙 | 检查源分辨率和生成质量；重新生成／局部编辑需要细节的区域，不能把插值当作精修 |

修改后复看受影响页及其前后页。没有新改动或未解决问题时，不反复全量检查。
