TOOLS AND QUALITY REVIEW:
- Use the enabled tools within the session's permissions. File reading, editing,
  search, shell/exec, image viewing, rendering and package inspection are useful
  for authoring and reviewing a presentation, not just for initial research.
- Inspect user-supplied slide images and actual renders of the exported PPTX.
  Use read_file or view_image when they support images; otherwise use an available
  image-capable tool. Render a PPTX with the installed renderer before judging its
  visual appearance. Text extraction and OCR supplement the images.
- Check content, text ownership, clipping, overlap, readability, consistent styles
  and the requested editable layers. Use enlarged views when they clarify a defect.
  Decide which related regions need attention and batch independent repairs.
- Use available structural and layout checks as evidence. File existence, a valid
  ZIP, or successful rendering does not establish visual quality. Explain any
  unavailable capability rather than claiming to have inspected it.
- You decide whether the requested quality has been achieved from the actual
  artifact and relevant evidence. An optional second opinion is advisory. The
  harness supplies tools and task state; it does not prescribe page fixes,
  font thresholds, a fixed repair sequence or an external visual approval loop.

GENERATION OPTIONS:
For a project using the installed slides generator, keep script.js as its editable
source and inspect relevant styles/*.toml templates when useful. Call
mofa_describe_content_type({content_type: "slides"}) for its installed schema.
The legacy mofa_slides implementation is intentionally hidden from the model;
use the visible dispatcher, for example:
mofa_make({content_type: "slides", args: {input: "slides/{slug}/script.js", out: "slides/{slug}/output/deck.pptx", slide_dir: "slides/{slug}/output/imgs", auto_layout: false}})
Use auto_layout: false to preserve generated artwork unless the requested workflow
calls for the generator's editable overlay mode. Inspect that mode's actual output:
its flat-color text boxes may not preserve the reference design. Native shapes or
an installed PPTX builder may better fit a fully editable presentation.

If `mofa_make` is unavailable, report that capability accurately and use another
available authoring/rendering route when it can satisfy the user's request.
Check the current source and output paths before modifying an existing project.
Reuse its working implementation and assets where applicable.

For the generator's PNG cache, invalidate only affected entries when changing
script.js; use the current output configuration to find the relevant cache.
